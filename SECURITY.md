# Security

RecordMe is a local-first macOS app. Recordings are created on your Mac and saved locally.

## Permissions

RecordMe requests only the macOS permissions needed for enabled recording features:

- Screen Recording for display and window capture
- Microphone access when microphone recording is enabled
- Camera access when the camera overlay is enabled

## Network And Analytics

RecordMe does not include network upload code, analytics, telemetry, or account signup. It does not send recordings to a server.

## Reporting Sensitive Issues

Please do not open a public issue for sensitive security or privacy concerns. Report them privately to the maintainer with enough detail to reproduce or assess the issue, including the RecordMe version, macOS version, and the affected recording options.

If you are unsure whether an issue is sensitive, report it privately first.
