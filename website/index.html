A FEW THINGS TO KNOW

Glad you asked.

Small app. Short answers.

Is RecordMe really free?

Yes. RecordMe is free to download and use, with no subscription or account required. The source code is available under the MIT license.

What do I need to run it?

A Mac running macOS 15.1 or later. RecordMe is a native macOS app; Windows and Linux aren't supported. You'll grant screen recording permission when setting it up, plus microphone or camera permission if you use those features.

How do I install it?

Download the DMG, open it, and drag RecordMe into your Applications folder. The current community build is unsigned, so macOS may block the first launch. After trying to open the app, use System Settings → Privacy & Security → Open Anyway if available, then confirm. See Apple's guide to opening apps for details.

Where do my recordings go?

Your recordings are saved as MP4 files on your Mac. RecordMe doesn't upload them to a server. You decide where to store them and who to share them with.

Can I contribute or request a feature?

Absolutely. Open an issue on GitHub with your idea or bug report, or read the contributing guide to get started with the code.
